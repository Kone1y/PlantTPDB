# Benchmark 04 — Agent QA

Evaluation of the PlantTP Agent covering literature retrieval, composite
answer quality, claim-level evidential support, and automated-evaluator
comparison. The QA benchmark contains 240 questions; abstention is
evaluated separately on a 60-question challenge set.

## Data

- `data/qrels/chunk_level_qrels.json` — frozen chunk-level relevance
  judgments (240 questions, with gold chunk texts)
- `data/qrels/document_relevance.json` — document-level relevance judgments
  (two-phase adjudication; see `docs/benchmark_annotation_protocol.md`)
- `data/evidence_windows/evidence_windows.json` — per-question 18-chunk
  evidence windows with per-chunk document identifiers and section labels;
  relevance judgments live in
  `data/qrels/` (chunk-level gold members and document-level relevance)
- `data/claims/claim_adjudication_record.xlsx` — expert-adjudicated
  claim-level listing (3,534 claims: initial/final label, rationale, review
  status)
- `data/claims/ragas_eval_input_3534.jsonl.gz` — frozen input for the
  automated evaluator (claims + evidence snapshots + human labels)
- 60 challenge cases (45 designated as not safely answerable /
  15 answerable).
- `data/candidate_caches/` — frozen deduplicated candidate pools for the
  reranking ablation (the shared candidate set of both arms)

## Results and reported metrics

**Retrieval (240 questions; `code/final_scoring/score.py` regenerates the
per-question metrics from the frozen qrels and evidence windows):**
MRR 0.967, R@18 0.790, nDCG@10 0.684.

**Composite answer quality (three independent evaluators, 0–100 anchored
rubric in `docs/answer_quality_rubric.txt`):**
mean composite score **82.9 / 100** (E1 82.2, E2 83.9, E3 82.7). This is a
rubric-based quality score, not an accuracy.

**Claim-level evidence support (expert-adjudicated, 3,534 claims):**
**95.6%** of claims (3,379 / 3,534) are evidence-supported; **41.3%** of
answers (99 / 240) contain at least one not-supported claim. Adjudication
procedure: `docs/benchmark_annotation_protocol.md` §5.

**Automated evaluator comparison (the automated-evaluator comparison panel;
RAGAS v0.4.3,
DeepSeek-V4-Flash, temperature 0):** over **all 3,534 claims**, binary
agreement with the human-reviewed labels is **82.9%** (2,929 / 3,534) —
83.7% (2,828 / 3,379) for human-supported claims and 65.2% (101 / 155) for
human-not-supported claims. Per-claim results:
`results/ragas_full_comparison_per_claim.csv` ("Final per-claim automated
and human assessment results"); evaluation code and frozen input:
`code/ragas_eval/`. Agreement rates are descriptive and are reported
alongside, not in place of, the human-reviewed labels.

**Abstention:** On the separate 60-question abstention challenge, the
system correctly abstained on 42 of the 45 questions designated as not
safely answerable (**93.3%**); all 15 answerable controls were answered.

Answers and retrieved passages in this benchmark are source-linked to the
archived corpus; evidence-support rates characterize the benchmark answers
and do not imply that all generated content is independently verified.

## Code

- `code/final_scoring/score.py` — chunk-level retrieval scoring (MRR, R@5,
  R@18, P@5, P@18, nDCG@10) from the frozen qrels and evidence windows.
- `code/final_scoring/dataset_stats.py` — recomputes the answer-quality
  and abstention summary figures (counts, rates, 95% CIs, ICC) from the
  archived data.
- `code/reranking_ablation/rescore_dense.py` — no-reranking (bi-encoder
  dense ranking) ablation arm: ranks the identical frozen candidate pools
  (`data/candidate_caches/`) by embedding cosine similarity on the frozen
  question text, scores the top-18 window with the formulas imported from
  `score.py`. Requires the vector store
  and embedding model (`--vdb` / `--model`); the full vector store is not
  part of this deposit, so this step needs a locally rebuilt store. The full-pipeline arm needs no
  separate script (scored by `score.py` from the frozen evidence windows);
  its per-question results are regenerated by `score.py`;
  `results/dense_arm_per_question.json` archives the no-reranking
  arm's per-question results.
- `code/ragas_eval/evaluate_claim_support.py` — automated
  claim–evidence support evaluation for the automated-evaluator
  comparison panel. Compares pre-extracted atomic claims with
  human-reviewed labels using the RAGAS Faithfulness NLI step. Usage:Usage:
  ```bash
  export DEEPSEEK_API_KEY=sk-...
  pigz -dc data/claims/ragas_eval_input_3534.jsonl.gz > input.jsonl
  python3 code/ragas_eval/evaluate_claim_support.py --input input.jsonl --output rerun
  # validation without API calls:
  python3 code/ragas_eval/evaluate_claim_support.py --input input.jsonl --dry-run
  ```
  Run configuration (model, parameters, input hash, RAGAS version):
  `results/ragas_full_comparison_manifest.json`.
